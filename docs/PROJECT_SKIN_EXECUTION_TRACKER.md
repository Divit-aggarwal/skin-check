## 6. Operating rules

1. This tracker is the project source of truth. 2. Never silently change architecture decisions. 3. No DONE without evidence (commit, validated artifact, research report or explicit owner decision). 4. Implementation completion is not production verification; research completion is not scientific validation. 5. LATER stays LATER. 6. Agents never invent evidence. 7. Every BLOCKED task names its blocker; every task has a next action. 8. Dependencies are explicit. 9. On completion, update this Markdown file, then rebuild the XLSX with the script; record commit SHA and test/typecheck/lint/build/deploy evidence. 10. Destructive production actions stop at OWNER ACTION. 11. No Terraform apply on the engine path without separate authorization. 12. No secrets here.
